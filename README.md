# Silent Route

A desktop hacker investigation game with realistic systems and a strong story.

Download the Windows x64 installer from [the latest release](https://github.com/GeorgeWebDevCy/silent-route-releases/releases/latest).

This public repository hosts installers, signatures, checksums, and the automatic update feed. Development source is maintained separately in a private repository.

## Updates

The game automatically checks this repository's `latest.json` release asset over HTTPS. It offers installation when a newer release is available, verifies the installer signature, saves your current investigation, and restarts through the installer. You can also choose **Check for updates** from the game menu. The game remains playable offline.

Older builds without the updater need this installer once. No GitHub account or Git installation is required to play or receive updates.

## Preview features

- Fullscreen desktop game with windowed controls and separate main/pause menus.
- Offline world map with independent home/server city choices.
- Fictional Linux userland, sessions, routes, evidence and a reactive defender.
- Original music, mechanical keyboard feedback, effects and optional local voice narration.

The campaign contains eleven investigations across five acts: an opening live-system mission and ten authorized forensic export cases, with a casebook, recurring contacts, evidence correlation and disclosure-dependent outcomes. All targets are fictional; commands operate on the game simulation.

## Version rule

Development pushes on the same calendar day increment the minor number. The first push on a different day increments the major number and resets the minor number. Dates use Asia/Nicosia time. Patch is currently zero.

Third-party geography notices are included in the release assets.
